# FoddyApp 🏃‍♂️

Ứng dụng đặt đồ ăn trực tuyến hiện đại tích hợp Real-time Tracking, Firebase Firestore và Gemini AI.

## 🚀 Bắt đầu nhanh

### Yêu cầu hệ thống
- Android Studio Ladybug | 2024.2.1+
- JDK 17+
- Android SDK 35 (Target)

### Cài đặt
```bash
git clone https://github.com/your-repo/foddyapp.git
cd foddyapp
./gradlew build
```

### Chạy ứng dụng
```bash
./gradlew installDebug
```

## 🛠️ Công nghệ sử dụng
- **UI**: Jetpack Compose (Material 3)
- **DI**: Hilt (Dagger Hilt)
- **Database**: Room Persistence Library
- **Backend**: Firebase Firestore, Firebase Auth
- **AI**: Google Gemini AI (Gợi ý món ăn thông minh)
- **Map**: Google Maps Compose SDK
- **Kiến trúc**: MVVM, Clean Architecture, StateFlow, Coroutines
- **Image**: Coil

## 📝 Ghi chú chuyển đổi
- **App ID cũ**: `com.example.foodle`
